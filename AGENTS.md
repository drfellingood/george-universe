# George Universe Agent Instructions

Before making any code changes:

1. Read:

   * docs/GEORGE-UNIVERSE-BIBLE.md
   * docs/HOME-PAGE-V1.md
   * docs/INSPIRATION-V1.md

2. Follow the design philosophy in those documents.

Core rules:

* George Universe is not a portfolio website.
* It is a personal universe.
* Inspiration is the most important section.
* Content is more important than animation.
* Never create generic startup or agency layouts.
* Home should remain minimal.
* Inspiration should feel like a digital archive and creative museum.
* Make small safe changes.
* Preserve existing functionality.
* Explain the plan before editing.

After changes:

* Run lint.
* Run build.
* Summarize changed files.
